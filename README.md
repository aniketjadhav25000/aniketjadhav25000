A multi-agent AI application that automates LinkedIn content generation and refinement.

**Key Features:**

- Built Writer and Reviewer agents using LangGraph.
- Implemented conditional routing and iterative refinement.
- Integrated Tavily web search for research-based content generation.
- Containerized and deployed the full-stack application using Docker.

**Tech Stack:** Python, LangGraph, FastAPI, React.js, Google Gemini, Groq, Tavily, Docker.

#### 🎓 Conditional RAG College Assistant

A LangGraph-based chatbot that intelligently routes student queries and retrieves relevant information from college documents.

**Key Features:**

- Implemented conditional routing for academic, fee-related, and general queries.
- Built a RAG pipeline using FAISS and Hugging Face embeddings.
- Used document chunking and semantic retrieval to find relevant information.
- Optimized query handling by bypassing unnecessary retrieval for general questions.

**Tech Stack:** Python, LangGraph, LangChain, Groq, FAISS, Hugging Face Embeddings, Streamlit.
