### 2. Conditional RAG College Assistant Chatbot

Developed a Conditional RAG chatbot that routes student queries into academic, fee-related, or general categories and retrieves relevant information from college documents.

**Highlights:**
- Implemented query classification and conditional routing using LangGraph.
- Built a document processing and retrieval pipeline.
- Generated embeddings using Hugging Face.
- Stored and retrieved document embeddings using FAISS.
- Integrated LLM-based response generation using Groq.

**Technologies:** Python, LangGraph, LangChain, RAG, FAISS, Hugging Face, Groq.
